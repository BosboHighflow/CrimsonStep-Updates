# Crimson Step updates

Official content update channel for Crimson Step by BosboHighflow.

This repository contains signed update metadata and downloadable game builds/content packages. It does not contain the development project or signing keys.

Players: install the Windows build or Android APK once, then use **Settings → Updates**. On Android, install APK upgrades over the existing app to preserve settings. Content updates apply after restarting the game. Both players must use the same content version.

The public update channel is free to download and does not require a GitHub login.
